# Dhanotiya Automobiles — Website

A responsive, bilingual (English/Hindi) static website for the electric scooter showroom in Manasa.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Upload the contents of this folder to any static hosting provider (for example, GitHub Pages, Netlify, or Vercel static hosting). No build step is required.

## Before publishing

- Confirm the displayed starting price and any current offers.
- Replace the illustrative scooter crops in `assets/` with approved, current Zelio product images. Current model names, specs and model-specific prices are intentionally not asserted.
- Test both phone numbers, WhatsApp links and the map pin on a mobile device.
- Add a privacy notice if analytics, forms, or tracking are added later.

The website uses Google Fonts and Google Maps, which require an internet connection. The WhatsApp buttons open a pre-filled enquiry message.
